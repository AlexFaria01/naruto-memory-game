# Naruto Memory Quest

Um jogo da memória inspirado no universo de Naruto. Escolhe o teu nível, enfrenta a IA Kage ou joga com um amigo e encontra os pares de shinobi ao som de uma banda sonora original inspirada em Konoha.

## Tecnologias

- React 19
- Vite 7
- Tailwind CSS 4
- TypeScript

## Como executar

É necessário ter o Node.js e o npm instalados.

```bash
npm install
npm run dev
```

Depois, abre no navegador o endereço indicado pelo Vite.

## Build de produção

```bash
npm run build
```

Os ficheiros otimizados são gerados na pasta `dist/`.
